# Лабораторная работа №1

Реализация вещественного генетического алгоритма для многомерной оптимизации
функции Альпина №1 (индивидуальный вариант `V=11`, `d=10`).

## Требования

- Python 3.10 или новее;
- используются только стандартные библиотеки Python;
- готовые пакеты оптимизации не используются.

## Запуск

Один воспроизводимый запуск:

```text
python lab1_ga.py
```

Полная серия экспериментов (20 seed, две конфигурации ГА и случайный поиск):

```text
python lab1_ga.py --run-experiments
```

Результаты появятся в каталоге `results/`: `results.csv`, `trajectory.csv` и
`convergence.svg`. Параметры зафиксированы в `config.json`.
